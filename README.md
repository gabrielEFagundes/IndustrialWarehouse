# 🏭 Industrial Warehouse

A program to help people manage their Industrial Warehouse

## 🔎 Focus

This program was focused on error treatment, so if you find any bugs, feel free to open a issue / PR!

## ✨ Features

```java
+---- Industrial Warehouse Management System ----+
| 1- Sign New Supplier                           |
| 2- Sign New Material                           |
| 3- Register Entrance Note                      |
| 4- Create Material Requisition                 |
| 5- Attend Requisition                          |
| 6- Cancel Requisition                          |
| 0- Exit                                        |
+------------------------------------------------+
```
